# Module 01 — Interactive Knowledge Map

## 1. Purpose
To create an interactive visual system that connects Ayurvedic knowledge, Sanskrit terminology, medicinal plants, classical texts and scientific research.

## 2. Main Features

1. Search Ayurvedic concepts, herbs and Sanskrit terms.
2. Display connected concepts through an interactive knowledge graph.
3. Show relationships between herbs, properties, diseases and classical references.
4. Display source references for available information.
5. Allow users to click a concept and explore its connected information.
6. Provide filters for classical texts, herbs, research and Sanskrit terminology.

## 3. Example User Journey

User searches for Ashwagandha.

The platform displays:
- Common name: Ashwagandha
- Sanskrit name: Ashwagandha
- Botanical name: Withania somnifera
- Traditional references
- Ayurvedic properties
- Related concepts
- Available scientific research
- Source citations

## 4. User Interface

- Search bar
- Interactive graph
- Information panel
- Filters
- Source reference links

## 5. Data Requirements

Every knowledge entry should contain:
- Unique identifier
- Concept name
- Sanskrit name, if available
- Category
- Description
- Relationships
- Source reference
- Verification status

## 6. Important Rules

- Do not invent connections.
- Every factual relationship should have a traceable source.
- Separate traditional Ayurvedic descriptions from modern scientific findings.
- Clearly mark information that has not been verified.

## 7. Initial MVP

Start with a small knowledge graph containing 10–20 verified Ayurvedic concepts and a limited number of medicinal plants.
