# IP AYURVEDA OS — MVP Scope

## 1. Objective
Build the first functional version of IP AYURVEDA OS with a usable dashboard, Ayurveda source library, herb database and source-verified research assistant.

## 2. Features for Version 1

### A. Dashboard
- Platform branding
- Navigation menu
- Module overview
- Search entry point
- Recent activity

### B. Source Library
- Add source records
- Search sources
- Store title, author, publication and source URL
- Track source type and verification status

### C. Herb Database
- Search herbs
- Display common, Sanskrit and botanical names
- Display traditional references
- Display modern research references
- Display safety information
- Show source citations

### D. Research Assistant
- Ask questions in natural language
- Retrieve information from the approved source library
- Generate answers based on retrieved information
- Display supporting citations
- Show when evidence is insufficient
- Distinguish traditional knowledge from modern scientific evidence

## 3. MVP Acceptance Criteria

The first version is considered functional when:

1. A user can open the dashboard.
2. A user can search the source library.
3. A user can open a herb record.
4. A user can ask an Ayurveda research question.
5. The assistant can retrieve relevant approved sources.
6. The answer displays traceable citations.
7. Unsupported information is not presented as verified fact.
8. The website works on desktop and mobile browser sizes.

## 4. Excluded from Version 1

- Full mobile application
- Advanced interactive knowledge graph
- Full Sanskrit learning system
- Advanced product launch automation
- Large-scale document ingestion
- Medical diagnosis or treatment recommendations

These will be considered in later releases.

## 5. Development Priority

Priority 1: Dashboard and application foundation.

Priority 2: Source library and herb database.

Priority 3: Research retrieval and citations.

Priority 4: Testing, corrections and deployment.

## 6. Development Rule

Complete, test and review each feature before starting the next major feature.
